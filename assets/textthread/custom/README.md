# Your own text-thread sounds (optional)

Text-thread reels use original synthesized tones by default (`"sfxPreset": "soft"`), so you don't need anything here.

For `"sfxPreset": "custom"`, put three short files in this folder:
- `sent.mp3`: plays when a blue (me) bubble lands (~0.3 s swoosh)
- `received.mp3`: plays when a grey (them) bubble lands (~0.4 s soft ding)
- `typing.mp3`: soft keyboard taps under the typing dots (~2 s)

Make them yourself, e.g. with ElevenLabs Sound Effects ("soft short message sent swoosh, UI sound, 0.3 seconds"),
or use any sound you are licensed to use. Don't use sounds extracted from Apple / Android system files.
These files are git-ignored.
