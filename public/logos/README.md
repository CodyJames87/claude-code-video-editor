# Logos (bring your own)

No third-party logos ship with this repo. Put logo files here (PNG with transparency or SVG) and reference them in
props as `"logoSrc": "logos/<file>.png"` (Logo Chip in `style/effects-library.md`). Files in this folder are git-ignored.

Use only logos you are allowed to use, exactly as provided (no recoloring, stretching or combining), only to refer to
that product, and never in a way that suggests the company endorses you. Official sources:

- Your own brand: your logo files.
- Claude / Claude Code (Anthropic): the press kit linked from https://www.anthropic.com/news ("Media assets"), also on
  https://brandfolder.com/anthropic
- Grok (xAI): https://x.ai/legal/brand-guidelines ("Download Logos"). Read the usage terms there first.
- Anything else: the company's own brand / press page.
